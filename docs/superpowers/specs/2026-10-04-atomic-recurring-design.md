# Atomic recurring journals

The existing monthly journal can leave a header without lines after interrupted requests. Its header-only retry check then advances `last_posted`, permanently skipping the financial entry. Two schedules sharing the first eight UUID characters also share an accounting identity.

The authorized repair adds one bounded, security-invoker RPC that locks a recurring schedule, validates an eligible consecutive month using the database WIB date, writes the journal header and balanced lines, and advances `last_posted` in one transaction. Existing monthly days 1–28, first-run current month, active/inactive controls and a maximum twelve-month catch-up remain unchanged. The app requests each due month through this RPC and surfaces failures; month-end must not lock a period after recurring posting fails.

New source references use the full UUID plus period, while `source='recurring'` stays compatible with ledger filters. Existing short references are reused only when their schedule prefix is unambiguous and their header has complete balanced lines. Incomplete, missing or ambiguous historical progress markers stop processing for manual review; no historical repair/backfill runs automatically. Replay returns the existing journal and never creates another entry. A disabled schedule cannot produce a new journal. The existing branch-access helper controls posting; definitions outside the caller's scope are skipped without updating their markers. The history screen excludes incomplete or ambiguous entries from successful-run counts and flags them for review.

SQL integration tests use fictional isolated PostgreSQL fixtures and roll back. They cover line-write and progress-marker failure, sequential catch-up, repeated and concurrent requests, WIB due dates, closed periods, active accounts, branch access and legacy identity compatibility. Application tests cover the real catch-up orchestration and history mapping. No production data, external messages, recurrence extensions or global posting-helper changes are included.
