## Instruksi rilis dan rollback

1. Integrasikan/rilis PR103 lebih dahulu; rekonsiliasi main jika berubah.
2. Release lane memeriksa parity RPC baseline/akses dan migration history pada project target yang ditetapkan. Terapkan **hanya** migration baru `20261023121700_clinic_therapy_note.sql`, sekali, dalam transaksi dengan error-stop. Jangan menjalankan ulang237 migration lokal terhadap target. Tidak ada backfill atau perubahan angka.
3. Deploy app sesudah kolom/RPC tersedia. Verifikasi exact main SHA dan deployment terminal. Simulasi pengguna tetap deferred sesuai instruksi user; belum dicentang di sini.
4. Rollback app terlebih dahulu, lalu bila diperlukan restore RPC lama melalui [rollback](../rollback/2026-10-23-clinic-therapy-note.sql). Kolom dan nilai tersimpan tetap dipertahankan. Jangan drop kolom atau mengubah data klinis lama. Request nonempty dari versi baru harus diperiksa hasil tersimpannya sebelum retry menggunakan app lama, karena isi request berbeda memang harus ditolak.
