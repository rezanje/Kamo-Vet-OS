# R04 — saved snapshot versus GL 1301 by branch (partial)

The existing closing report already shows immutable saved inventory values for one, several, or all accessible branches. This change reads the current inventory GL 1301 balance through the saved close date and shows each selected branch's snapshot, GL, and difference. It links each branch to Buku Besar 1301 with the same cutoff. Branchless 1301 journals are called out separately only in the all-branch view; they are not silently allocated to a branch or included in branch totals. Missing COA 1301 and incomplete snapshot values remain unavailable rather than zero. All figures use Decimal arithmetic; incomplete/error reads fail the report rather than returning a partial GL.

The GL comparison is a **current read of journals dated through the saved cutoff**, not an immutable historical ledger snapshot. Later backdated journals can change it. The report neither posts nor proposes an adjustment entry, and its difference is a review lead, not evidence of the correct counterpart or valuation basis. Source journals and target financial policy still need finance review. Arbitrary-date FIFO valuation remains unsupported: `stock_moves` began with a synthetic opening row in migration 0074 based on then-current item buy price, so pre-migration acquisition costs and complete opening financial history cannot be inferred from this table. No target data was read or changed and no migration/security policy was added.

Dummy fixtures cover two branches, the exact closing cutoff, a later journal exclusion, branchless GL, unrelated accounts, missing COA/snapshot values, query failure, missing count, invalid amounts, and missing branch metadata. Focused test and scoped lint results are recorded with the draft PR. Full R04 acceptance remains partial until an authoritative FIFO history or saved close source and source-backed ledger reconciliation are available; field UAT is deferred.
