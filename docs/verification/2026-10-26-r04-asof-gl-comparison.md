# R04 — GL 1301 comparison for saved-event as-of valuation (partial)

This follow-up depends on the saved-close report in PR #210 and the moving-average event as-of report in PR #227. It reads the existing `coa_accounts`, `journal_lines`, and joined `journal_entries` through existing authenticated RLS and the separate Buku Besar module check. No migration, new privilege, posting, costing-setting change, or target-data write is included.

For dates on or after moving-average activation, the report compares each selected branch's exact Decimal event value with the authorized GL 1301 debit minus credit balance for journal dates through the same end-of-day cutoff. It shows their difference, selected-branch totals, and a link to the existing Buku Besar detail. It fetches journal lines in exact-count pages, filtered to selected branch IDs. Journal entries without a branch are shown separately only when the user can access all branches and selects them all; they are excluded from branch subtotals. If account 1301 is absent, the comparison is unavailable. Incomplete/error pages or invalid numbers stop the report rather than show a plausible partial balance.

The GL amount is a **current read of journals dated on or before the selected date**, not a locked historical snapshot. A journal entered or corrected later with an older date can change the displayed difference. The GL query follows the current Buku Besar convention, which includes original journals together with any reversal journals. It does not assert that a zero difference certifies reconciliation: the valuation uses today's `warehouses.branch_id` assignment for old events. The warehouse activity audit is metadata-only, began after some historical changes, and is not readable by FINANCE; it cannot prove prior branch ownership. The report labels this boundary beside the comparison. A branchless journal is never silently assigned to a branch.

FIFO and pre-activation as-of values remain unavailable because authoritative historical cost layers are absent. For an earlier date, current stock cannot prove a vanished or missing event stream. The source-event continuity and today's bidirectional stock checks from PR #227 still apply. Field UAT, target-data reconciliation, historical branch dimension, and authoritative FIFO history remain R04 gaps.

Fixtures cover two branch balances, future and unrelated account exclusion, exact high-precision debit/credit, branchless accounting, module denial, unavailable account, malformed amount, server error/missing exact count, and 1,201 paged journal lines. They also assert detail-to-branch-to-total event reconciliation and the date-filtered GL query. No clinical, accounting, or legal policy was invented for any difference.
